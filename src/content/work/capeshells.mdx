      The<span class="italic"> Identity</span>
    </h2>
    <div class="prose">
      <p>The system is built around a primary stacked lockup — mark, wordmark, and tagline — for signage, letterhead, and anywhere the brand has room to breathe. A horizontal lockup handles tighter formats: stationery, van doors, web headers. For small-format use — social avatars, packaging, favicons — the mark drops into a circular badge, with the name and URL set in a ring around it.</p>
      <p>The system runs on two channels. Digital surfaces — the website, social — carry a gradient running from sea teal to land terracotta, with the mark set in flat white against it. Print and fleet applications use a monochrome version, black on off-white or reversed, for one-color production and consistent reproduction on vinyl and paper.</p>
    </div>
  </div>
</section>
